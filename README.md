# CAPA B2B Supplier Collector

One Chrome extension collects supplier listings from **IndiaMART Export**, **Made-in-China**, and **TradeIndia**. Choose the site from the **Marketplace** dropdown in the extension popup.

In `chrome://extensions/`, enable **Developer mode**, click **Load unpacked**, and select [`b2b-collector-extensions/tradeindia`](b2b-collector-extensions/tradeindia/). This is the existing TradeIndia folder, which now contains the combined extension. Chrome needs no build step or npm dependencies.

See the [extension guide](b2b-collector-extensions/tradeindia/README.md) for site features, backup and upgrade instructions, and development checks.
